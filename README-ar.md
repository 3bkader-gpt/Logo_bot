# 🎨 Logo Bot - بوت إضافة العلامات المائية

بوت تيليجرام لإضافة علامات مائية (Logos) على الصور. يتضمن أنماط متعددة لوضع العلامة، حجم وشفافية قابلة للتخصيص، إدارة المستخدمين، ودعم نشر Koyeb.

## ✨ المميزات

- 🖼️ **إضافة علامات مائية**: إضافة شعارات على الصور بسهولة
- 📍 **أنماط متعددة**: خيارات مختلفة لوضع العلامة (زاوية، وسط، إلخ)
- 🎚️ **قابل للتخصيص**: حجم وشفافية قابلة للتعديل
- 👥 **إدارة المستخدمين**: تتبع وإدارة المستخدمين
- 🚀 **نشر Koyeb**: دعم نشر سهل على Koyeb
- 🎯 **سهل الاستخدام**: واجهة بوت بسيطة وواضحة

## 🚀 البدء السريع

### المتطلبات

- Python 3.8+
- حساب Telegram Bot Token
- صورة الشعار (Logo)

### التثبيت

1. استنسخ المستودع:
```bash
git clone https://github.com/3bkader-gpt/Logo_bot.git
cd Logo_bot
```

2. ثبت المتطلبات:
```bash
pip install -r requirements.txt
```

3. قم بإعداد ملف `.env`:
```bash
cp .env.example .env
# أضف BOT_TOKEN و LOGO_PATH
```

4. قم بتشغيل البوت:
```bash
python main.py
```

## ⚙️ الإعدادات

### إعداد Telegram Bot

1. تحدث مع [@BotFather](https://t.me/BotFather)
2. أنشئ بوت جديد واحصل على Token
3. أضف Token في ملف `.env`:
```
BOT_TOKEN=your_bot_token_here
LOGO_PATH=path/to/your/logo.png
```

### تخصيص العلامة المائية

يمكنك تعديل:
- **الحجم**: نسبة حجم العلامة من الصورة
- **الشفافية**: مستوى الشفافية (0-255)
- **الموقع**: موضع العلامة (أعلى يسار، وسط، إلخ)

## 📝 الاستخدام

1. ابحث عن البوت في Telegram
2. أرسل صورة تريد إضافة علامة مائية عليها
3. اختر موضع العلامة
4. اختر حجم وشفافية العلامة
5. احصل على الصورة المعدلة

### الأوامر المتاحة

- `/start` - بدء استخدام البوت
- `/help` - عرض المساعدة
- `/settings` - إعدادات العلامة المائية

## 🛠️ التقنيات المستخدمة

- **Python**: لغة البرمجة الأساسية
- **python-telegram-bot**: مكتبة بوت Telegram
- **Pillow (PIL)**: معالجة الصور
- **Flask**: خادم الويب (لنشر Koyeb)
