## 🎯 نظرة عامة

**Logo Bot** هو بوت تيليجرام لإضافة علامات مائية (Logos) على الصور. يتضمن أنماط متعددة لوضع العلامة، حجم وشفافية قابلة للتخصيص، إدارة المستخدمين، ودعم نشر Koyeb.

### ✨ لماذا Logo Bot؟

- 🖼️ **سهولة الاستخدام** - أضف علامات مائية بخطوات بسيطة
- 🎨 **قابل للتخصيص** - حجم وشفافية وموقع قابل للتعديل
- 📍 **أنماط متعددة** - خيارات مختلفة لوضع العلامة
- 🚀 **نشر سهل** - دعم كامل لـ Koyeb

---

## 🌟 المميزات

### 🚀 المميزات الرئيسية

| الميزة | الوصف |
|--------|-------|
| 🖼️ **إضافة علامات مائية** | إضافة شعارات على الصور بسهولة |
| 📍 **أنماط متعددة** | خيارات مختلفة لوضع العلامة (زاوية، وسط، إلخ) |
| 🎚️ **قابل للتخصيص** | حجم وشفافية قابلة للتعديل |
| 👥 **إدارة المستخدمين** | تتبع وإدارة المستخدمين |
| 🚀 **نشر Koyeb** | دعم نشر سهل على Koyeb |
| 🎯 **سهل الاستخدام** | واجهة بوت بسيطة وواضحة |

### 🎨 خيارات التخصيص

- ✅ **الحجم**: نسبة حجم العلامة من الصورة (10% - 50%)
- ✅ **الشفافية**: مستوى الشفافية (0 - 255)
- ✅ **الموقع**: 9 مواضع مختلفة (أعلى/وسط/أسفل × يسار/وسط/يمين)
- ✅ **التنسيقات**: دعم PNG, JPG, JPEG, WEBP

## 🚀 التثبيت

### خطوات التثبيت

```bash
# 1. استنسخ المستودع
git clone https://github.com/3bkader-gpt/Logo_bot.git
cd Logo_bot

# 2. أنشئ بيئة افتراضية
python -m venv venv
source venv/bin/activate  # على Windows: venv\Scripts\activate

# 3. ثبت المتطلبات
pip install -r requirements.txt

# 4. قم بإعداد ملف البيئة
cp .env.example .env
# قم بتعديل ملف .env بإضافة بياناتك
```

### إعداد ملف `.env`

```env
BOT_TOKEN=your_telegram_bot_token_here
LOGO_PATH=path/to/your/logo.png
```

## ⚙️ الإعدادات

### إعداد Telegram Bot

1. تحدث مع [@BotFather](https://t.me/BotFather)
2. أنشئ بوت جديد باستخدام `/newbot`
3. اتبع التعليمات واحصل على Token
4. أضف Token في ملف `.env`:
   ```env
   BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
   ```

### إعداد الشعار

1. احضر صورة الشعار بصيغة PNG (شفافية خلفية موصى بها)
2. ضع الصورة في مجلد المشروع
3. أضف المسار في ملف `.env`:
   ```env
   LOGO_PATH=./logo.png
   ```

### تخصيص الإعدادات الافتراضية

يمكنك تعديل الإعدادات الافتراضية في الكود:

```python
DEFAULT_SIZE = 0.15      # 15% من حجم الصورة
DEFAULT_OPACITY = 200    # شفافية متوسطة
DEFAULT_POSITION = "bottom-right"  # أسفل يمين
```

## 📖 الاستخدام

### خطوات الاستخدام

1. ✅ **ابحث عن البوت** في Telegram
2. ✅ **ابدأ المحادثة** باستخدام `/start`
3. ✅ **أرسل صورة** تريد إضافة علامة مائية عليها
4. ✅ **اختر الموضع** من القائمة
5. ✅ **اختر الحجم** (صغير/متوسط/كبير)
6. ✅ **اختر الشفافية** (شفاف/متوسط/معتم)
7. ✅ **احصل على الصورة** المعدلة

### الأوامر المتاحة

| الأمر | الوصف |
|-------|-------|
| `/start` | بدء استخدام البوت |
| `/help` | عرض المساعدة والأوامر |
| `/settings` | إعدادات العلامة المائية |
| `/logo` | تغيير الشعار |

### أمثلة الاستخدام

```
المستخدم: أرسل صورة
البوت: اختر موضع العلامة المائية:
       1. أعلى يسار
       2. أعلى وسط
       3. أعلى يمين
       ...

المستخدم: 1
البوت: اختر حجم العلامة:
       1. صغير (10%)
       2. متوسط (20%)
       3. كبير (30%)

المستخدم: 2
البوت: [يرسل الصورة المعدلة]
```
